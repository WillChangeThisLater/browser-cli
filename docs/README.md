# Documentation

This folder contains research, design notes, analysis, and technical documentation for the browser CLI.

## Files

| File | Type | Description |
|------|------|-------------|
| `openclaw-research-findings.md` | Research | Analysis of OpenClaw's browser architecture and lessons learned |

## Adding Documentation

When adding new docs:
1. Use clear, descriptive filenames
2. Include date and purpose at the top
3. Link to related docs or issues
4. Add entry to this README

## Coalescing Notes

If you find redundant documentation:
1. Merge overlapping content
2. Keep the most comprehensive version
3. Update links/references
4. Note what was consolidated
